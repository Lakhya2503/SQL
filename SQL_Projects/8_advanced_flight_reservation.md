# Project 8: Flight Reservation System (Advanced)

## Objective
Master dynamic state tracking, complex aggregations, and query optimization by modeling an airline's booking and ticketing infrastructure.

## Core Requirements
1.  **Airports:** Code (PK, e.g., JFK, LAX), City, Country.
2.  **Flights:** ID, Source Airport Code, Destination Airport Code, Departure Time, Arrival Time, Base Price, Total Seats.
3.  **Passengers:** ID, Name, Passport Number.
4.  **Tickets:** Ticket Number (PK), Passenger ID, Flight ID, Seat Number, Class (Economy, Business, First), Final Price Paid, Booking Timestamp.

## Tasks & Queries to Write
1.  **Available Seats Calculation:** Write a view named `VW_Flight_Availability` that mathematically calculates the remaining seats per class for every upcoming flight (Total Seats minus `COUNT(Tickets)`) in real-time.
2.  **Dynamic Pricing Strategy:** Write an `UPDATE` query (or procedure) that increases the `Base Price` of a flight by 20% if there are fewer than 10 seats remaining and the departure is less than 48 hours away.
3.  **Window Functions:** Using `ROW_NUMBER()`, write a query to automatically assign sequential Seat Numbers (e.g., 1A, 1B, 1C) to pending tickets on a flight, ensuring Business Class passengers are seated first.
4.  **Reporting:** Find the top 3 most profitable airports (Total Revenue generated by all flights originating from that airport) in the last quarter.

## Expected Learnings
*   Creating dynamic Views (`VW_`).
*   Combining `UPDATE` statements with complex `WHERE` aggregations.
*   Using Window Functions for sequential numbering.
